# Migrating to V3

When upgrading from `v2` to `v3.*` support for Python 3.9 has been dropped.

Additionally the minimum required version of the msgspec dependency
is now 0.20.0 - which may be breaking for some users on a lower version.
This change was made to support Python 3.14.

The `id` property was removed from the `Snapshot` model. Remove any references
in your code base to this property.
